# V13 配置

## 控制目标

应用的默认配置必须能够安全地用于互联网环境。

本章提供为实现这一目标所需的各类配置指导，包括开发、构建和部署期间应用的配置。

覆盖主题包括防止数据泄露、安全管理组件之间的通信，以及保护秘密。

## V13.1 配置文档

本节概述文档要求，说明应用如何与内部和外部服务通信，以及如何防止因服务不可访问导致可用性损失。它还处理与秘密相关的文档。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.1.1** | 验证应用的所有通信需求都已记录在文档中。这必须包括应用依赖的外部服务，以及最终用户可能提供外部位置、随后由应用连接该位置的场景。 | 2 |
| **13.1.2** | 验证对于应用使用的每项服务，文档定义了最大并发连接数（例如连接池限制），以及达到该限制时应用如何表现，包括任何回退或恢复机制，以防止拒绝服务状况。 | 3 |
| **13.1.3** | 验证应用文档为其使用的每个外部系统或服务（例如数据库、文件句柄、线程、HTTP 连接）定义了资源管理策略。这应包括资源释放流程、超时设置、故障处理；如果实现了重试逻辑，还应说明重试限制、延迟和退避算法。对于同步 HTTP 请求-响应操作，应强制使用较短超时，并禁用重试或严格限制重试，以防止级联延迟和资源耗尽。 | 3 |
| **13.1.4** | 验证应用文档定义了对应用安全至关重要的秘密，并根据组织威胁模型和业务要求制定了轮换计划。 | 3 |

## V13.2 后端通信配置

应用会与多个服务交互，包括 API、数据库或其他组件。这些服务可能被视为应用内部组件，但不包含在应用标准访问控制机制中；也可能完全外部化。无论哪种情况，都必须配置应用，使其能够安全地与这些组件交互，并在需要时保护该配置。

注意：“安全通信”章节提供了传输中加密指导。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.2.1** | 验证不支持应用标准用户会话机制的后端应用组件之间的通信，包括 API、中间件和数据层，均经过认证。认证必须使用独立服务账号、短期令牌或基于证书的认证，而不是密码、API 密钥，或具有特权访问的共享账号等不变凭据。 | 2 |
| **13.2.2** | 验证后端应用组件之间的通信，包括本地或操作系统服务、API、中间件和数据层，使用被授予最小必要权限的账号执行。 | 2 |
| **13.2.3** | 验证如果必须使用凭据进行服务认证，调用方使用的不是默认凭据（例如 root/root 或 admin/admin）。 | 2 |
| **13.2.4** | 验证使用允许列表定义应用允许通信的外部资源或系统（例如用于出站请求、数据加载或文件访问）。该允许列表可以在应用层、Web 服务器、防火墙，或多个不同层组合实现。 | 2 |
| **13.2.5** | 验证 Web 服务器或应用服务器配置了资源或系统允许列表，限定服务器可以向哪些目标发送请求，或从哪些目标加载数据或文件。 | 2 |
| **13.2.6** | 验证当应用连接到独立服务时，会遵循每个连接的文档化配置，例如最大并行连接数、达到最大允许连接数时的行为、连接超时和重试策略。 | 3 |

## V13.3 秘密管理

秘密管理是保护应用所用数据的一项基本配置任务。密码学的具体要求位于“密码学”章节，而本节聚焦于秘密的管理和处理。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.3.1** | 验证使用秘密管理解决方案（例如密钥保管库）安全创建、存储、控制访问并销毁后端秘密。这些秘密可以包括密码、密钥材料、与数据库和第三方系统的集成凭据、基于时间令牌的密钥和种子、其他内部秘密以及 API 密钥。秘密不得包含在应用源代码中，也不得包含在构建产物中。对于 L3 应用，必须涉及 HSM 等硬件支持的解决方案。 | 2 |
| **13.3.2** | 验证对秘密资产的访问遵循最小权限原则。 | 2 |
| **13.3.3** | 验证所有密码学操作都使用隔离的安全模块（例如保管库或硬件安全模块）执行，以安全管理并保护密钥材料，防止其暴露到安全模块之外。 | 3 |
| **13.3.4** | 验证秘密被配置为根据应用文档过期并轮换。 | 3 |

## V13.4 非预期信息泄露

生产配置应经过加固，避免披露不必要数据。许多这类问题很少被评为重大风险，但经常会与其他漏洞串联使用。如果这些问题默认不存在，就会提高攻击应用的门槛。

例如，隐藏服务端组件版本并不能消除修补所有组件的需要；禁用目录列表也不能消除使用授权控制或避免文件放入公共文件夹的需要，但它确实提高了门槛。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.4.1** | 验证应用部署时不包含任何源代码控制元数据，包括 .git 或 .svn 文件夹；或者这些文件夹无论从外部还是应用自身都无法访问。 | 1 |
| **13.4.2** | 验证生产环境中所有组件都禁用了调试模式，以防止暴露调试功能和信息泄露。 | 2 |
| **13.4.3** | 验证 Web 服务器不会向客户端暴露目录列表，除非这是明确预期行为。 | 2 |
| **13.4.4** | 验证生产环境不支持 HTTP TRACE 方法，以避免潜在信息泄露。 | 2 |
| **13.4.5** | 验证文档（例如内部 API 文档）和监控端点不会暴露，除非这是明确预期行为。 | 2 |
| **13.4.6** | 验证应用不会暴露后端组件的详细版本信息。 | 3 |
| **13.4.7** | 验证 Web 层配置为只提供具有特定文件扩展名的文件，以防止非预期的信息、配置和源代码泄露。 | 3 |
