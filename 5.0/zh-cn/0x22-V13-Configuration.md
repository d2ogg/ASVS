# V13 配置

## 控制目标

应用采用默认配置并在互联网环境中使用时，必须是安全的。

本章说明在开发、构建和部署阶段应如何配置应用，才能达到这一目标。

覆盖主题包括防止数据泄露、安全管理组件之间的通信，以及保护秘密。

## V13.1 配置文档

本节规定配置文档需要包含哪些内容，包括应用如何与内部和外部服务通信、如何避免外部服务不可用时拖垮应用，以及如何记录应用使用的秘密。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.1.1** | 验证文档记录了应用的所有通信需求，包括应用依赖的外部服务，以及由最终用户提供目标地址、再由应用连接该地址的场景。 | 2 |
| **13.1.2** | 验证文档为应用使用的每项服务规定了最大并发连接数（例如连接池上限），并说明达到上限时应用如何处理，包括采用哪些回退或恢复机制来防止拒绝服务。 | 3 |
| **13.1.3** | 验证文档为应用使用的每个外部系统或资源（例如数据库、文件句柄、线程和 HTTP 连接）规定了管理策略。策略必须说明何时释放资源、如何设置超时和处理故障；如果允许重试，还应规定重试次数、间隔和退避算法。对于同步 HTTP 请求与响应，应设置较短的超时时间，并禁止重试或严格限制重试，防止延迟级联和资源耗尽。 | 3 |
| **13.1.4** | 验证文档列出了对应用安全至关重要的秘密，并根据组织的威胁模型和业务要求规定了轮换计划。 | 3 |

## V13.2 后端通信配置

应用会与 API、数据库等多个服务或组件交互。这些对象可能属于应用内部，但不受应用常规访问控制机制管理；也可能完全由外部提供。无论属于哪种情况，都必须安全配置应用与它们之间的连接，并在必要时保护配置本身。

注意：“安全通信”章节提供了传输中加密指导。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.2.1** | 验证不支持应用常规用户会话机制的后端组件，在相互通信时都会进行身份认证，包括 API、中间件和数据层。认证应采用独立服务账号、短期令牌或证书，不能使用密码、API 密钥、具有特权的共享账号等长期不变的凭据。 | 2 |
| **13.2.2** | 验证本地服务、操作系统服务、API、中间件和数据层等后端组件相互通信时，使用的账号只拥有完成任务所需的最低权限。 | 2 |
| **13.2.3** | 验证服务认证确实需要使用固定凭据时，调用方没有使用 `root/root`、`admin/admin` 等默认凭据。 | 2 |
| **13.2.4** | 验证应用通过允许列表限制可以通信的外部资源和系统，包括出站请求、数据加载和文件访问的目标。允许列表可以在应用、Web 服务器、防火墙或多个层面共同实施。 | 2 |
| **13.2.5** | 验证 Web 服务器或应用服务器配置了目标允许列表，明确限制服务器可以向哪些地址发送请求，以及可以从哪些位置加载数据或文件。 | 2 |
| **13.2.6** | 验证应用连接独立服务时，遵循文档为该连接规定的配置，包括最大并发连接数、达到上限后的处理方式、连接超时和重试策略。 | 3 |

## V13.3 秘密管理

秘密管理是保护应用所用数据的一项基本配置任务。密码学的具体要求位于“密码学”章节，而本节聚焦于秘密的管理和处理。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.3.1** | 验证应用使用密钥保管库等秘密管理方案，安全地创建、存储、授权访问和销毁后端秘密。秘密包括密码、密钥材料、数据库和第三方系统的接入凭据、基于时间令牌的密钥和种子、其他内部秘密以及 API 密钥。不得把秘密写入源代码或构建产物。L3 应用必须采用 HSM 等硬件支持的方案。 | 2 |
| **13.3.2** | 验证对秘密的访问遵循最小权限原则。 | 2 |
| **13.3.3** | 验证所有密码学操作都在隔离的安全模块中执行，例如密钥保管库或硬件安全模块。密钥材料必须始终由安全模块管理和保护，不能暴露到模块之外。 | 3 |
| **13.3.4** | 验证秘密按照应用文档规定的时间失效并完成轮换。 | 3 |

## V13.4 非预期信息泄露

生产环境应经过配置加固，避免泄露不必要的信息。这类问题单独出现时往往不构成重大风险，却经常被攻击者与其他漏洞组合利用。默认关闭这些信息泄露渠道，可以提高攻击难度。

例如，隐藏服务端组件版本并不能消除修补所有组件的需要；禁用目录列表也不能消除使用授权控制或避免文件放入公共文件夹的需要，但它确实提高了门槛。

| # | 描述 | 级别 |
| :---: | :--- | :---: |
| **13.4.1** | 验证部署产物不包含 `.git`、`.svn` 等版本控制元数据。如果确实存在这些目录，则无论外部用户还是应用自身都不能访问。 | 1 |
| **13.4.2** | 验证生产环境中的所有组件都已关闭调试模式，避免暴露调试功能或泄露内部信息。 | 2 |
| **13.4.3** | 验证 Web 服务器默认不向客户端显示目录列表；只有业务明确需要时才可以启用。 | 2 |
| **13.4.4** | 验证生产环境不支持 HTTP TRACE 方法，以避免潜在信息泄露。 | 2 |
| **13.4.5** | 验证内部 API 文档等非公开文档和监控端点默认不会对外暴露；只有明确需要时才可以开放。 | 2 |
| **13.4.6** | 验证应用不会暴露后端组件的详细版本信息。 | 3 |
| **13.4.7** | 验证 Web 层配置为只提供具有特定文件扩展名的文件，以防止非预期的信息、配置和源代码泄露。 | 3 |
